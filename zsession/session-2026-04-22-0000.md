## Decisions & Rationale
- **Lazy Proxy over removing the export**: `controlPanelDb` and `auth` are used directly in `payment.service.ts` and test files. Removing the exports would require touching more files; the Proxy gives the same interface with deferred initialization.
- **`avantej-core-server` not `avantej-core` for the server**: `apps/web/wrangler.jsonc` already had `name: "avantej-core"` for the frontend. Using the same name would overwrite the web worker on deploy.
- **`BETTER_AUTH_URL` must be set to the server's deployed URL**: Better-Auth uses this for cookie domain and callback URLs; leaving it as `localhost` would break session cookies in production.

## Notes
- Cloudflare Workers script validation (error 10021) runs module-level code at deploy time. Any top-level code that throws (e.g. missing env vars) will block deployment — keep module init side-effect-free.
- `getEnvVar()` in both `db.ts` and `better-auth.ts` reads from `cloudflare:workers` module first, then falls back to `process.env`. This pattern works for both Workers runtime and local Node.js/test environments.
- `zsession/` is not gitignored — consider adding it to `.gitignore` if you don't want session logs committed.
