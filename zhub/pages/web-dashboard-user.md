## 1. What It Does

**Purpose (user perspective):** View and manage all organization members (users). Simple table listing members with roles, status, and admin-specific actions (Login as).

**Produces:** Table of members with columns defined by createColumns() factory. Columns vary based on caller's role (admin sees more, e.g., "Login as" button).

**On success:** Table renders all members for selected organization. No create/edit UI in this page.

**On failure / error states:** Loading spinner, guard check (no org selected), no explicit error handling shown.

---

## 2. How It Works

**Execution flow:**
1. On mount: Fetch organizationId from useUserContext
2. Check caller's role: `hasRole(["admin"])` → controls column visibility
3. Load members: `client.members.list({ organizationId })`
4. Build columns dynamically: `createColumns({ callerIsAdmin, organizationId })`
5. Render DataTable with columns and members data

**Inputs:**
- URL param: none (org context from session)
- DataTable props: columns, data (members)

**State management:**
- TanStack Query: `queryKey = ["members", organizationId]`
- No local state (read-only page)

**Outputs:** Table rows of members with dynamic columns

**Side effects:** None (read-only)
