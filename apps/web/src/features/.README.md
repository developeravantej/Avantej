# features/

Feature-scoped modules extracted from god-files during Phase 4 cleanup.

## Convention

```
src/features/<name>/
  components/   # UI components specific to this feature
  hooks/        # Custom hooks (if any)
  types/        # TypeScript types/interfaces (if any)
```

## Rules

- Each subfolder contains code for ONE feature slice only.
- Components here may import from `@/components/ui/*` and `@/lib/*` but NOT from other feature folders.
- Shared logic that multiple features need lives in `@/components/` or `@/lib/`, not here.
- Tests may be colocated as `*.test.tsx` next to the file they test.
