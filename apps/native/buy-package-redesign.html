Key Design Changes

✦ Replaced 7-dot stepper with thin progress bar + step counter (saves ~80px per screen)

✦ Trainer cards replace dropdown modal — better scanability and touch targets

✦ Info screen shows summary of prior selections as confirmation

✦ Consistent 7-step count across all screens (was mixed 7/8)

✦ Review uses compact row layout instead of heavy cards-in-cards

✦ Done screen celebrates with green check, clean summary, and 3 clear next actions
