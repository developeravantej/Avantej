# Documents (e.g. Terms PDF)

Place **terms.pdf** here for offline viewing in the app.

- The app will bundle this file and show it when users tap "Terms and Conditions" (and related links) on the sign step.
- Replace the placeholder `terms.pdf` with your actual Terms & Conditions PDF.
- Later, the app can be updated to fetch the PDF from the backend instead; local file is used when available for offline support.
