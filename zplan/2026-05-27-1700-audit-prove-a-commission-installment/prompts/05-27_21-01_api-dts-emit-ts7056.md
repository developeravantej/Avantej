# Fix `@avantej-core/api` package dts emit — TS7056 inferred-type-too-large

> Handoff prompt generated 2026-05-27 21:00 · Branch: `audit-prove-a/commission-installment-20260527-1700` · Project: Avantej

## Mission

`bunx turbo build --filter=@avantej-core/api` currently fails with `TS7056: The inferred type of this node exceeds the maximum length the compiler will serialize. An explicit type annotation is needed.` at `packages/api/src/routers/index.ts:12` (the merged `appRouter` export). The error blocks dts emission, which forces the web app to fall back to a stale dist when running `bun check-types` without `--force`. Add an explicit type annotation (or restructure the router so each sub-namespace is typed independently) so the dts emitter can serialize the result.

## Current State

`packages/api/src/routers/index.ts`:
```ts
import type { RouterClient } from "@orpc/server";
import * as serverRouterTypes from "./_types/server-router-types";
import { baseRouter, customerProfilesRouter, invitationRouter } from "./base-router";

export { baseRouter } from "./base-router";

/** Full router for client type inference (server procedures merged at runtime). */
export const appRouter = {
  ...baseRouter,
  auth: serverRouterTypes.authRouterType,
  invitations: { ...invitationRouter, ...serverRouterTypes.serverInvitationRouterType },
  customerProfiles: { ...customerProfilesRouter, ...serverRouterTypes.serverCustomerProfilesRouterType },

  partnerStripe: serverRouterTypes.partnerStripeRouterType,

  // ... etc
};
export type AppRouter = typeof appRouter;
export type AppRouterClient = RouterClient<typeof appRouter>;
```

The error fires at line 12 (`export const appRouter = {`) because the inferred type of that object expression exceeds the compiler's serialization limit when emitted as a single declaration.

`bunx turbo build --filter=@avantej-core/api` output:
```
RollupError: src/routers/index.ts(12,14): error TS7056: The inferred type of this node exceeds the maximum length the compiler will serialize. An explicit type annotation is needed.
```
