### Decisions Made
- **`or()!` non-null assertion with biome-ignore comment**: `drizzle-orm`'s `or()` return type is `SQL<unknown> | undefined` (for 0-arg case). We always pass 2 args so it's always non-null, but TypeScript cannot see that. Used `!` assertion guarded by `if (search)` block to avoid adding an import of SQL type just for a cast.
- **Filter row design**: Used `flex-wrap` row with labeled inputs so the row degrades gracefully on narrower viewports. Clear button uses `X` icon for conventional UX.
- **Plans query uses `activeOnly: true`**: Only active plans shown in dropdown, but `plansMap` is used for display of all codes so orphan codes from historical rows still show their name if the plan is in the map.

### Issues Encountered
- **`or()` type inference**: `SQL<unknown> | undefined` caused TS2345 on `conditions.push(...)`. Fixed with `!` non-null assertion.
